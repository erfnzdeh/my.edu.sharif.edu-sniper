Sharif course catalogue, static read API

A snapshot of the courses offered on my.edu.sharif.edu, regenerated by hand each semester and served as static JSON. It exists so the sniper can resolve a course's unit count without opening a WebSocket or spending one of its very limited API requests.

Endpoints

PathWhat it holds
api/courses.jsonEvery offered course, keyed by CODE-GROUP
api/meta.jsonGeneration time, course count, field documentation

Shape

{
  "40404-1": { "u": 1, "v": 0, "t": "آز مهندسی نرم‌افزار", "c": 30 },
  "22034-2": { "u": 3, "v": 0, "t": "معادلات دیفرانسیل",   "c": 50 }
}
FieldMeaning
uUnits. The portal range checks this, and sending the wrong number fails the registration with INCORRECT_UNIT_NUMBER
v1 when the course accepts a variable unit count from 0 to u
tCourse title
cCapacity at generation time. A snapshot, and stale almost immediately

Regenerating

EDU_TOKEN='<Authorization header>' node tools/catalogue/dump.mjs

Contains public course data only. No student identifiers, enrolments, or favourites are ever written here.
